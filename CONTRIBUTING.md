# Руководство для участников (Contributing Guide)

Мы приветствуем предложения, исправления ошибок и улучшение документации проекта **AEGIS-HIVE**.

## Как внести свой вклад

1. **Создание форка и ветки:**
   * Сделайте форк репозитория и создайте тематическую ветку (`git checkout -b feature/awesome-feature` или `fix/network-recalc`).
2. **Требования к коду:**
   * Проект использует **Godot 4.3+** и язык **GDScript 2.0**.
   * Придерживайтесь статической типизации параметров и возвращаемых значений функций (`func calculate(delta: float) -> void:`).
   * Все взаимодействия между системами выполняются через `EventBus`, чтобы не создавать жестких циклических зависимостей.
   * Ознакомьтесь с подробными гайдами в каталоге `docs/`:
     * `docs/STYLE_GUIDE.md` — стандарты архитектуры и оформления.
     * `docs/RULES.md` — правила разработки и пайплайна.
3. **Проверка тестов:**
   * Перед созданием Pull Request обязательно запустите регрессионные тесты:
     ```bash
     godot --headless --path . tests/test_runner.tscn
     ```
   * Все тесты должны завершаться с кодом `exit 0`.
4. **Pull Request:**
   * Опишите суть изменений, приложите скриншоты (при изменении UI/графики) и убедитесь, что тесты проходят.
