# AEGIS-HIVE

Изометрическая научно-фантастическая стратегия на Godot 4, посвящённая проектированию и развитию многоярусной индустриальной мегаструктуры.

## О проекте

В **AEGIS-HIVE** строительство разворачивается не на плоской карте, а по вертикали. Игрок управляет развитием автономного комплекса, осваивая поверхность, углубляясь в недра и возводя подвесные верхние ярусы на массивных опорах.

Ключевой акцент сделан на физической связности инфраструктуры: производство работает только при наличии подведённой энергии и непрерывных линий снабжения сырьём.

### Что уже реализовано

* **Многоярусное пространство (Z-слои):** Полноценная поддержка независимых изометрических сеток ярусов (`TileMapLayer`). Новые верхние уровни требуют возведения несущих колонн на нижних, а подземные — работы буровых комплексов.
* **Сетевая логистика (графы в реальном времени):**
  * **Энергосеть:** распределение мощности от генераторов через кабели к потребителям с мгновенным пересчётом контуров при разрушении линий и защитой приоритетных узлов при перегрузках.
  * **Цепочки поставок:** доставка руды от карьеров к заводам и складам по конвейерным путям.
  * **Вертикальный транспорт:** шахты-лифты 2×2, передающие ресурсы и питание между смежными этажами.
* **Оборонительный комплекс (Этап 3 — завершён):**
  * Защитный периметр и перекрытия: бронированные стены (`WallNode`) с динамическим обновлением сетки проходимости и **Бронепалубы** (`ArmorDeck`, `z > 0`), перехватывающие орбитальные и воздушные атаки над нижними ярусами с проекцией в оверлее `[F4]`.
  * Огневые точки: скорострельные автопушки и дальнобойные тяжелые рельсотроны (бонус `+20%` от сенсорных вышек) с централизованной синхронизацией боеприпасов `ammo` и учётом скорости игры и паузы.
  * Энергетические щиты: 2:1 изометрические купола, поглощающие входящий урон и поддерживающие принудительную боеготовность под протоколом «Эгида».
  * Логистика ремонта и деградация состояния: снижение КПД повреждённых зданий, визуализация повреждений (`<50% HP`) и руин (`0 HP` с расчисткой за `25%`), ремонтные депо (`50 HP/с`).
  * Индуктивная целостность опор: потеря опорной колонны приводит к каскадному урону верхних ярусов и тиковому износу с тревожной индикацией в списке ярусов.
* **Командная панель (`CommandPanel`), Директивы и Исследования:**
  * Немедленный **Боевой энергопереброс** и живые **динамические приоритеты энергосети** (`#1..#4`).
  * Вкладка **«Исследования»** (`ResearchManager`), открывающая **Протокол «Эгида»** (укрытие населения в бункерах и постоянная готовность щитов).
* **Индустриальный бруталистский HUD:** двухуровневый модульный док строительства на 19 зданий, верхняя панель ресурсов (вкл. `Боеприпасы`) и счетчика волн, оверлеи (`F1` Сеть, `F2` Логистика, `F4` Броня), левая командная панель (`F5`/`F6`) и правый переключатель ярусов; адаптивная раскладка для `1920×1080` и `1280×800` (Steam Deck).
* **Динамическая индикация:** здания визуально сообщают о проблемах (пульсирующая окантовка фундамента при отсутствии энергии или сырья без отключения спрайтов).
* **Экономика и население:** расчёт производства по тикам, вместимость жилых блоков и естественный прирост колонистов.
* **Режим песочницы:** мгновенное переключение между стандартным геймплеем и режимом неограниченных ресурсов клавишей `F3`.

## Быстрый старт

### Требования
* **[Godot Engine 4.7.2](https://godotengine.org/download)** (для запуска из исходного кода; готовая Linux-сборка в Releases / Actions не требует установки движка).

### Запуск на Linux / Steam Deck (без установки Godot)
1. Скачайте архив `aegis-hive-linux-x86_64.tar.gz` со страницы **Releases** (или из вкладки **Actions** на GitHub).
2. Распакуйте и запустите:
   ```bash
   tar -xzf aegis-hive-linux-x86_64.tar.gz
   ./aegis-hive.sh
   ```
   > Для старых видеокарт без поддержки Vulkan используйте fallback на OpenGL 3: `./aegis-hive.sh --gl`

### Запуск из исходного кода (Windows / Linux)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Amirrima37/AEGIS-HIVE.git
   ```
2. **Быстрый запуск на Linux:**
   ```bash
   bash scripts/linux/aegis-hive.sh
   ```
   *(Скрипт автоматически найдёт системный `godot` / `godot4` / Flatpak, проимпортирует ресурсы при первом запуске и стартует игру.)*
3. **Через редактор Godot:** откройте проект по файлу `project.godot` и нажмите **F5** (или выполните из терминала: `godot --path . --headless --import && godot --path .`).

## Управление

| Клавиша / Действие | Функция |
|---|---|
| `W`, `A`, `S`, `D` / Стрелки | Перемещение камеры |
| `СКМ` (зажать) или `ПКМ` (зажать) | Панорамирование поля зрения |
| `Колёсико мыши` | Масштабирование (zoom к курсору) |
| `Q` / `E` | Переключение активного яруса (вверх / вниз) |
| `Shift + Q` | Запрос на возведение нового яруса выше (требует опорную колонну) |
| `Shift + E` | Запрос на бурение нового подземного яруса |
| `ЛКМ` | Выбор здания / установка на сетку / протяжка кабелей (drag-to-build) |
| `ПКМ` / `Esc` | Сброс текущего режима строительства или сноса |
| `Пробел` | Пауза / возобновление симуляции |
| `1`, `2`, `3` | Скорость симуляции (1x, 2x, 3x) |
| `F1` / `F2` / `F4` | Оверлеи данных (Энергосеть / Логистика / Броня и палубы) |
| `F5` / `F6` | Вкладки командной панели (`Директивы` / `Исследования`) |
| `F3` | Переключение между стандартным и тестовым (неограниченным) режимом |

## Архитектура проекта

Кодовая база разбита на независимые модули и опирается на событийно-ориентированную модель (`EventBus`):

```
AEGIS-HIVE/
├── autoload/        # Глобальные менеджеры (EventBus, GameState, ResourceManager)
├── data/buildings/  # Resource-файлы спецификаций всех 19 зданий (.tres)
├── scenes/          # Сцены мира, HUD и тестового окружения
├── scripts/
│   ├── buildings/   # Логика зданий, КПД/руины, сетка занятости (OccupancyGrid), размещение
│   ├── camera/      # Изометрическая камера с плавным зумом, сканкодами и геймпадом
│   ├── defense/     # Подсистема обороны (DefenseSystem, TurretManager, ShieldController, AmmoSupply, RepairDepot, WallNode)
│   ├── economy/     # Тиковый оркестратор с динамическими приоритетами (TickManager) и исследования (ResearchManager)
│   ├── networks/    # Графы сетей (PowerGrid, SupplyChain, ShaftElevator) и 2D-оверлеи (F1/F2/F4)
│   └── world/       # Менеджеры уровней, индуктивная целостность опор и генерация ярусов
├── ui/              # Модульный бруталистский HUD (BuildToolbar, CommandPanel, LayerIndicator, OverlayToggle, SpeedControl)
├── tests/           # Автоматизированные тесты Этапов 0–3, GUI и совместимости с Linux/Steam Deck
└── docs/            # Подробная техническая и архитектурная документация
```

Подробное описание архитектуры и графа зависимостей доступно в [STRUCTURE.md](STRUCTURE.md) и [ROADMAP.md](ROADMAP.md).

## Тестирование

В проект встроен комплекс сквозных автотестов, проверяющий топологию сетей, тики экономики, механику ярусов и выравнивание спрайтов:

```bash
godot --headless --path . tests/test_runner.tscn
```
Успешный прогон завершается с кодом `exit 0`.

## Источники вдохновения

Визуальная атмосфера и концепция многоярусного мира сформировались под впечатлением от архитектурного брутализма мегаструктур («BLAME!»), эстетики циклопических покинутых уровней («Girls' Last Tour») и инженерно-индустриального стиля («Neon Genesis Evangelion»). 

В геймплейном плане проект ориентируется на классические изометрические градостроительные и логистические стратегии старой школы.
