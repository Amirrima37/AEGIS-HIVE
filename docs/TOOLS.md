# TOOLS — Инструменты и пайплайны генерации ассетов

> **Важное правило проекта:** Никакой ручной текстовой генерации мешей (obj/gltf кодом вслепую).  
> Все 3D-модели, текстуры и спрайты создаются исключительно через проверенные внешние инструменты, готовые библиотеки ассетов и скрипты пайплайна.

---

## 1. Спецификация изометрических ассетов

* **Проекция:** Dimetric / Isometric 2:1
* **Базовый шаг тайла:** `128 × 64` px
* **Размеры зданий:**
  * 1×1 тайл: холст `128 × 128` (база 128×64 + высота до 64 px)
  * 2×2 тайла: холст `256 × 256` (база 256×128 + высота до 128 px)
  * 3×3 тайла: холст `384 × 384` (база 384×192 + высота до 192 px)
* **Точка привязки (Offset / Pivot):** Центр нижнего ромба основания тайла.

---

## 2. Инструменты и источники ассетов

### А. Изометрические тайлы и здания (3D/2D)
1. **Бесплатные проверенные паки (Primary Fast Track):**
   * **Kenney Sci-Fi / Space Kit:** Бесплатные CC0 3D low-poly модели и 2D изометрические тайлы.
   * **itch.io Isometric Sci-Fi packs:** Бесплатные и CC0 тайлсеты.
2. **Рендеринг 3D-моделей в 2D изометрию:**
   * Камера в Blender / Godot: ортографическая, угол наклона `30°` (или `atan(0.5) ≈ 26.565°` для истинного 2:1 пиксель-арта), поворот по Z: `45°`.
   * Вывод: PNG с альфа-каналом в целевые разрешения (`assets/sprites/buildings/`).
3. **Плейсхолдерные скрипты:**
   * Программная генерация базовых геометрических спрайтов с маркерами через Python (`Pillow`) или Godot `Image`.

### Б. 2D-портреты персонажей, изометрические спрайты и иллюстрации
* **Инструмент:** Внешняя генерация пользователем (через аккаунт Gemini на модели Argon / Imagen в браузере или 3D-паки/Blender).
* **Пайплайн:**
  1. Claude Opus в плане этапа формирует отдельный блок со спецификациями: точный целевой путь файла, габариты, требования к изометрии (30°, без фона), палитра и готовый текстовый промпт.
  2. Пользователь генерирует ассеты отдельно от чата разработки и складывает файлы в указанные папки.
  3. Пользователь нажимает «Proceed» в плане этапа.
  4. Gemini Flash использует готовые файлы из указанных папок при сборке сцен и ресурсов.

### В. Нормализация спрайтов зданий под сетку (Auto-Alignment Pipeline)
Чтобы спрайты зданий любого масштаба и высоты никогда не «съезжали» с изометрической сетки, в проекте действует строгий геометрический инвариант:
1. **Ширина ромба основания (Diegetic Status Rim):** Строго равна `size.x * 128` px (1×1 = 128 px, 2×2 = 256 px, 3×3 = 384 px).
2. **Высота ромба основания:** Строго равна `size.x * 64` px (соотношение 2:1).
3. **Горизонтальное центрирование:** Ромб основания строго отцентрован по горизонтали (`X = width / 2`).
4. **Посадка на дно холста:** Нижняя вершина ромба основания расположена на `Y = canvas_height - 3` (2 px антиалиасинга).
5. **Формула выравнивания в коде (Sprite2D):**
   ```gdscript
   sprite_node.offset = Vector2(0, size.x * 32.0 + 3.0 - texture_height * 0.5 + data.base_offset_y)
   ```
6. **Скрипт автонормализации:**
   Любые новые сгенерированные или отрендеренные спрайты в `assets/sprites/buildings/` автоматически приводятся к стандарту запуском:
   ```powershell
   python scripts/tools/normalize_building_sprites.py
   ```
