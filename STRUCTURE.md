## 2. ТЕХНИЧЕСКИЙ РЕЕСТР ФАЙЛОВ И ПРАВИЛА АРХИТЕКТУРЫ

> [!NOTE]
> Данный раздел предназначен для парсинга и поддержания инвариантов ИИ-агентом при последующей генерации и модификации кода.

---

### ГЛОБАЛЬНЫЕ СИСТЕМНЫЕ ИНВАРИАНТЫ

1. **Связанность компонентов (Decoupling):**
   * Прямые жесткие ссылки между системами запрещены.
   * Все межсистемные взаимодействия (World <-> UI <-> Camera <-> Logic) происходят исключительно через сигналы `EventBus`.
   * Прямой вызов методов допускается только вниз по иерархии нод (родитель вызывает метод прямого потомка).
2. **Координатная система сетки:**
   * Проекция: 2D Dimetric/Isometric (форма ромба).
   * Соотношение сторон тайла: 2:1 (`tile_size = Vector2i(128, 64)`).
   * `tile_shape = TileSet.TILE_SHAPE_ISOMETRIC`.
   * `tile_layout = TileSet.TILE_LAYOUT_DIAMOND_DOWN`.
3. **Вертикальность (Z-Уровни):**
   * Базовый уровень: `z = 0` (Поверхность).
   * Верхние уровни: `z > 0` (Платформы, шпили). Требуют наличия опорной колонны (`support_pillar`) уровнем ниже.
   * Нижние уровни: `z < 0` (Геофронт, каверны). Требуют наличия буровой установки (`excavation_rig`) уровнем выше.
   * `TileMapLayer.z_index` каждого яруса равен `z * 10` во избежание визуальных артефактов наложения.
4. **Видимость и прозрачность ярусов:**
   * `diff == 0` (активный ярус): `modulate.a = 1.0`, `visible = true`.
   * `diff == 1`: полупрозрачный (`modulate.a = 0.24..0.28`), `visible = true`.
   * `diff == 2`: контурный (`modulate.a = 0.08`), `visible = true`.
   * `diff > 2`: `visible = false` (полное отсечение для сохранения FPS).
5. **Тиковая экономика:**
   * Фазовый расчет: сначала производство первичной энергии, затем потребление, затем добыча сырья, затем переработка вторичных материалов.
6. **Сетевая логистика и графы связности (PowerGrid, SupplyChain, ShaftElevator):**
   * Энергосеть (`PowerGrid`): проводниками тока выступают только `power_source`, `power_cable` и `elevator`. Здания-потребители (`power_consumer`, карьеры, заводы, жилые блоки) являются листьями графа и не передают ток сквозь себя. При разрыве кабельной цепи здание обесточивается (`connected_to_power = false`, `is_operational = false`).
   * Транспортная сеть (`SupplyChain`): проводниками потока сырья выступают `supply_source`, `supply_cable`, `warehouse` и `elevator`. Заводы (`supply_consumer`) являются листьями. Здание без снабжения получает `connected_to_supply = false` и останавливает производство.
   * Межъярусная связь (`ShaftElevator`): парные лифты 2×2 на идентичных XY-координатах соседних ярусов формируют виртуальные вертикальные связи в графах; ярусы без цепочки лифтов к z=0 изолированы от снабжения и энергии.
   * Интеграция с тиками: перед экономическими фазами `TickManager` выполняет Фазу 0 (`NetworkManager.recalculate_all()`), неактивные здания исключаются из фаз добычи и переработки.
7. **Геометрия и выравнивание спрайтов зданий (2:1 Grid Alignment):**
   * Ширина текстуры спрайта строго равна `size.x * 128` px (128 для 1×1, 256 для 2×2, 384 для 3×3).
   * Diegetic Status Rim основания идеально вписан в ромб сетки: нижняя вершина на `Y = canvas_height - 3` (с запасом 2px под антиалиасинг).
   * Центр ромба основания гарантированно совпадает с центром тайла через инвариантную формулу: `offset = Vector2(0, size.x * 32.0 + 3.0 - texture_height * 0.5 + data.base_offset_y)`.
   * Пайплайн автонормализации: `python scripts/tools/normalize_building_sprites.py`.
8. **Режимы игры (Standard и Unlimited / Sandbox):**
   * Переключение: клавиша `F3` или кнопка `BtnGameMode` в верхнем баре HUD.
   * `Standard Mode`: строгий баланс, проверка ресурсов при строительстве, списание затрат, создание ярусов строго через колонны и буровые.
   * `Unlimited Mode`: свободный режим для быстрого тестирования. `ResourceManager.can_afford` и `ResourceManager.spend` возвращают `true` без списания; в HUD отображается символ `∞`; создание ярусов вверх/вниз не блокируется.

### СПЕЦИФИКАЦИЯ ФАЙЛОВ

#### `docs/` (Регламенты, лор и статусы)
* **`docs/STAGES.md`** — Высокоуровневый роадмап и глобальный список этапов проекта.
* **`docs/STATE.md`** — Текущий статус активного этапа, результаты предыдущих и блокеры.
* **`docs/TOOLS.md`** — Инструкции по запуску инструментов генерации ассетов и моделей.
* **`docs/RULES.md`** — Регламент распределения ролей (Claude Opus / Gemini Flash) и протоколы работы.
* **`docs/STYLE_GUIDE.md`** — Руководство по миру, лору, эстетике мегаструктур и системный промпт для арт-генерации.

#### `scripts/networks/` (Подсистема логистики и сетей)
* **`scripts/networks/network_graph.gd`** — Базовый класс графа связности (список смежности, поиск в ширину BFS, проверка путей к источникам, расчет пространственной смежности тайловых построек).
* **`scripts/networks/power_grid.gd`** — Специализированный граф энергосети (проведение тока через кабели и шахты-лифты, обесточивание оторванных потребителей).
* **`scripts/networks/supply_chain.gd`** — Граф транспортной сети (доставка руды от карьеров и складов к перерабатывающим заводам по конвейерам).
* **`scripts/networks/shaft_elevator.gd`** — Вертикальные логистические лифты (объединение подграфов разных ярусов, проверка связанности ярусов с базовым z=0).
* **`scripts/networks/network_manager.gd`** — Центральный фасад и координатор логистики (слушает события стройки/сноса, инициирует синхронный пересчет всех сетей).
* **`scripts/networks/network_overlay.gd`** — Динамическая 2D-отрисовка оверлея связности (голубые линии электропередачи F1, янтарные линии транспортировки F2, индикация шахт).

#### `ui/`
* **`ui/overlay_toggle.gd`** — Панель управления видимостью сетевых оверлеев (кнопки переключения энергосети и транспорта).
