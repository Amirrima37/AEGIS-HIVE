# File Naming Rules

Strict requirement for all agents, subagents, and contributors on this project:

- **DO NOT** name files, directories, scenes, scripts, resources, assets, or artifacts using names, abbreviations, or references associated with external/foreign intellectual properties, games, anime, movies, or media (for example: `cs2`, `skylines`, `evangelion`, etc. are strictly prohibited in file names).
- All filenames must use descriptive, professional, in-universe, or functional terminology (e.g. `modular_dock`, `build_toolbar`, `defense_system`, `layer_manager`).
- If implementing an architecture or design inspired by an external mechanic or reference, name the files strictly according to their functional role in this project (e.g., `build_shelf.gd`, `category_dock.tscn`, `two_tier_toolbar.svg`).
